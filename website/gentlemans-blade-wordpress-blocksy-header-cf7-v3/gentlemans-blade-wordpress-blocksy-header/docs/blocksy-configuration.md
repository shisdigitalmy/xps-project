# Blocksy Configuration (v3)

## Import

1. Install **Blocksy** + **Blocksy Companion**, activate Blocksy.
2. **Appearance → Customize → Import/Export** (Companion) → import
   `blocksy/gentlemans-blade-blocksy-options.dat`.
3. Confirm: max site width 1280, palette gold `#E5A962` / bronze `#B07851` /
   ink `#14191F`, body font Montserrat, buttons rust `#C05621` → hover `#9A4519`.

## Notes

- The `.dat` carries no menu/logo/page/media IDs — safe across installs.
- Validated with structural checks (starts with the Blocksy template header,
  contains the target site URL and Montserrat, no `Inter` in root typography).
