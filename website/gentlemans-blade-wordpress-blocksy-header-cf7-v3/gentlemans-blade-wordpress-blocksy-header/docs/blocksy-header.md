# Blocksy Header + Menu (v3)

## Menu

**Appearance → Menus** → create `Primary`, add 6 Custom Links (URLs verbatim):

- HOME → `/`
- SERVICES → `/#services`
- EXPERIENCE → `/#experience`
- GALLERY → `/#gallery`
- BOOKING → `/#booking`
- VISIT → `/#visit`

Assign to the Blocksy header menu location.

## Header builder

**Appearance → Customize → Header**: main row = Logo (left) + Primary Menu
(center/right) + Button `Book Appointment` linking `/#booking` (right).
Enable Sticky (Always). Colors: row bg `#14191F`, links `#E2E8F0`,
hover `#E5A962`; menu typography Montserrat 600, uppercase, 14px,
letter-spacing 0.12em. Mobile: Logo + Hamburger → Blocksy off-canvas menu.

## No Elementor header

Do not build any header in Elementor. There is no header JSON in this package.
